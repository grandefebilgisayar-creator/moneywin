# Reply Playbook
Müşteriden gelen maile göre yapılacaklar.

## Reply Type 1 — Interest / Ask for info
- Cevap: proposal’ı gönder
- Kullan: `client-packs/first-client-action-kit/proposal/email-proposal.md`
- Sonra: discovery call planla

## Reply Type 2 — Question about price
- Cevap: değer öner, paketi açıkla
- Kullan: `client-packs/first-client-action-kit/proposal/package.md`
- Sonra: call daveti

## Reply Type 3 — Need time / not now
- Cevap: break-up email gönder
- Kullan: `client-packs/first-client-action-kit/emails/4-breakup.md`
- Sonra: 2 ay sonra takip et

## Reply Type 4 — Not interested
- Cevap: teşekkür, referans iste
- Kullan: `client-packs/first-client-action-kit/emails/referral-ask.md`
- Sonra: pipeline’dan çıkar

## Reply Type 5 — Ready to start
- Cevap: contract + payment link gönder
- Kullan: `client-packs/first-client-action-kit/proposal/contract-stub.md`
- Sonra: kickoff email gönder

## Genel Kural
- Her cevapta sonraki adımı açıkça belirt
- 24 saat içinde cevap ver
- Stage’i CSV’de güncelle
