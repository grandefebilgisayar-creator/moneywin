# How to Make Money With MoneyWin
## Model
- Sell automation packages to small businesses.
- Charge one-time or monthly.
- Repeat with different niches.

## First Money Path
1. Pick one niche: local services, clinics, shops, consultants.
2. Use outreach emails in `src/outreach/emails/`.
3. Track replies in `src/outreach/tracking/tracking.csv`.
4. Send proposal from `tools/proposal-template.md`.
5. Deliver starter package from `client-packs/starter-invoicing/`.
6. Ask for referral or retainer.

## Pricing
- Starter: $300
- Growth: $800
- Scale: $2,000/mo

## Growth Path
- 5 clients x $300 = $1,500 one-time
- 3 clients x $800 = $2,400 one-time
- 2 clients x $2,000/mo = $4,000/month recurring
