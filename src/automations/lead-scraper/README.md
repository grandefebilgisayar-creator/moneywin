# Lead Scraper
Collect and enrich lead lists from multiple sources.

## Problem
Leads are scattered across multiple sources and formats.

## Solution
Collect, normalize, and enrich leads into a single structured dataset.

## Inputs
- source query or location
- fields to extract
- output format

## Outputs
- leads CSV or JSON
- enrichment log

## Acceptance Criteria
- Output schema stable
- Duplicate handling defined
- Source attribution preserved
